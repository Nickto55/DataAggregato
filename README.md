# DataAggregato

**Aggregato** — это десктопное приложение на Python с графическим интерфейсом, предназначенное для автоматизации работы с данными: создания сводных таблиц из ежемесячных отчетов, сверки информации (например, ФИО) и формирования итоговых отчетов в формате Excel.

## Основные возможности

- **Сводные таблицы (Pivot Fusion)**: автоматический сбор и объединение данных из ежемесячных отчетов в единую структурированную таблицу.
- **Сверка данных (Construction Result)**: проверка и сопоставление ФИО и других ключевых показателей.
- **Графический интерфейс (GUI)**: современный и удобный интерфейс на базе `CustomTkinter` с поддержкой темной темы, перетаскиваемым окном без рамок и удобной панелью управления (хотбар).
- **Продвинутое логирование**: многоуровневая система логирования с цветовой индикацией для удобного отслеживания процесса обработки данных в реальном времени.
- **Экспорт в Excel**: сохранение итоговых результатов в файл (по умолчанию `Aggregato result.xlsx`).

## Технологический стек

- **Язык**: Python 3.x
- **GUI**: `CustomTkinter`, `tkinter`
- **Обработка данных**: `pandas`, `openpyxl` (для работы с Excel)
- **Дополнительно**: модуль `queue` для асинхронного обновления интерфейса и логов без блокировки основного потока.

## Установка и запуск
1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Nickto55/DataAggregato.git
   cd DataAggregato
   ```

2. **Создайте и активируйте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   venv\Scripts\activate     # Для Windows
   ```

3. **Установите необходимые зависимости**:
   ```bash
   pip install customtkinter pandas openpyxl
   ```


4. **Запустите приложение**:
   ```bash
   python scr/body.py
   ```

## Использование

1. Откройте приложение.
2. В главном окне укажите путь к файлу или директории с исходными отчетами (или используйте значение по умолчанию).
3. Выберите необходимые этапы обработки:
   - **Сбор ежемесячных отчетов** (Pivot Fusion)
   - **Сверка ФИО** (Construction Result)
4. Нажмите кнопку запуска и следите за процессом в окне логов.
5. Готовый результат будет сохранен в файл `Aggregato result.xlsx` в корневой папке (или по указанному вами пути).
